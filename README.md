📊 Sales Performance Dashboard: <br>
A Power BI dashboard for analyzing Amazon India sales trends in women's clothing.

📝 Overview <br>
This project showcases an interactive Power BI dashboard built to analyze and visualize Amazon India sales data, specifically for women’s clothing. It provides actionable insights to drive strategic decisions across sales performance, B2B metrics, and cancellations. <br>
The dataset includes 119,760 records and spans multiple sales categories and KPIs. The dashboard is split into four pages:

1. Overall Sales <br>
➡️Top-performing products <br>
➡️Orders by time <br>
➡️Sales by category <br>
➡️Key KPIs (Orders, Amount, B2B, etc.)

2. Category-Wise Sales <br>
➡️Sales across regions, sizes, and categories <br>
➡️Time-series performance <br>
➡️Category-specific KPIs

3. B2B Sales <br> 
➡️Business-to-business orders across regions and product types Cancellations

4. Cancellations <br>
➡️Cancellation trends over time <br>
➡️Impact of promotions on cancellations <br>
➡️Regional cancellation patterns


📂 Dataset Details: <br>
➡️Source: Kaggle (Sample Amazon India sales dataset) <br>
➡️Size: 119,760 rows | 24 columns <br>
➡️Key Columns: Amount, Category, Status, Date, Promotion-ids, B2B

📌 Skills & Techniques Used: <br>
🛠 Data Cleaning & Preparation: Missing values, duplicates, data typing, bucketing, and normalization <br>
🧮 DAX Functions: CALCULATE, DIVIDE, COUNTROWS, SUM, and more <br>
📈 KPI Analysis: Total Orders, Revenue, Quantity, B2B Orders, Shipped Orders, Cancelled Orders

📸 Insights & Highlights: <br>
👗 Top-selling products: Set & Kurta <br>
❌ Highest cancellations: Products with no promotion <br>
🏆 Most active region: Maharashtra <br>
📊 Sales vs. Quantity: Set and Kurta have similar quantities sold, but Sets generate higher revenue

🧰 Tools Used: <br>
➡️Power BI: Dashboard creation & visualization <br>
➡️DAX: For building calculated fields & KPIs <br>
➡️Power Query: Data transformation and cleaning <br>
➡️Excel/CSV: Source data handling

🎯 Challenges & Learnings: <br>
➡️Finding the balance between complex data and clear visuals <br>
➡️Creating an intuitive dashboard layout that conveys rich insights without overwhelming the user <br>
➡️Designing cross-filtering for multi-perspective storytelling
